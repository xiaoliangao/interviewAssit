# 05 · 转型叙事与面试故事库

简历负责拿到面试，叙事负责把面试变成 offer。转型者被刷掉，十有八九不是能力不够，而是**没能在 60 秒内让对方相信这次转型是想清楚的、不是走投无路的**。

## Part A · 转型叙事

一句话核心，三个版本。三个版本的**事实和逻辑必须完全一致**，只是详略不同——不一致会在多轮面试里被交叉验证出来。

**必须回答的三个疑虑**（招聘方心里真正在问的）：

1. **为什么离开？** — 面向未来，不说前东家坏话。「我想做 X，现在的位置做不了 X」永远优于「那边太乱了」
2. **为什么是这个方向？** — 要有**证据**，不是「我对这个很感兴趣」。你为此做过什么？读了什么？做了什么项目？跟谁聊过？没有行动的兴趣在招聘方眼里等于零
3. **凭什么是你？** — 用 02 模块那句「能力定位总结」。**你的优势恰恰在于你不是科班**——你带着一个纯科班没有的东西过来

三个版本：

```markdown
### 30 秒电梯版（面试开场"介绍一下自己"）
我在 <行业> 做了 <N> 年 <职能>，其中最有意思的部分是 <和目标岗位重叠的那部分>。
做到后来发现我真正想解决的是 <问题>，于是 <具体行动：做了什么项目/拿了什么结果>。
所以我现在找的是 <目标岗位>——我带着 <稀缺组合> 过来。

### Cover letter 版（150–200 字）
加一条最硬的成果 + 一句为什么是这家公司（要具体到这家，不能通用）

### 面试深聊版（2–3 分钟）
加时间线、加一个转折点的具体故事、加你为此付出的真实代价
（代价这一项很重要：它证明这不是一时兴起）
```

## Part B · STAR 故事库

从 00 资产清单的 B 层挑 **6–8 个**故事，覆盖下表的高频考察维度。一个故事可以覆盖多个维度，但不要让同一段经历撑起整场面试——面试官会觉得你只有这一件事可说。

| 维度 | 典型问法 |
|---|---|
| 最大成就 | 说一件你最自豪的事 |
| 失败与复盘 | 说一次搞砸的经历 |
| 冲突与影响力 | 怎么说服一个不听你的人 |
| 模糊中推进 | 信息不全时怎么决策 |
| 学习速度 | 怎么快速上手完全陌生的领域（**转型者的必考题**） |
| 数据驱动 | 用数据改变决定的一次 |
| 跨部门协作 | 推动一件不归你管的事 |

每个故事的格式（**T 和 R 各占一半篇幅**）：

```markdown
**故事 3：说服采购部改用新供应商** [证据·B4]
可答：冲突与影响力、数据驱动、跨部门协作
- S 情境：<一句话背景和利害关系>
- T 任务：<你具体负责什么——不要模糊成"我们团队">
- A 行动：<3 个具体动作，其中至少一个体现思考方式而非执行>
- R 结果：<数字 + 后续影响> __（需你补充：节省金额）__
- 如果追问"如果重来你会怎么做"：<一个真实的反思>
```

大部分人的故事死在 A 和 R：行动写成「我和他们沟通了」，结果写成「项目顺利完成」。A 要有**具体动作**，R 要有**数字和后续影响**。缺数字就留占位符（见 `evidence-and-data.md`），不要编。

最后一行的「如果重来」是加分项——面试官经常追问，提前准备的人极少。

## Part C · 弱点应答脚本

针对 00 资产清单 E 节列出的每一项风险，各准备一条。结构统一：**简短承认 → 不辩解 → 转向证据 → 停下来**。

```markdown
**空窗期 8 个月**
"我 X 月主动离开，原因是 <一句话，不抱怨>。这段时间我 <具体做了什么>。
现在回到职场，我很清楚我要找的是 <目标>。"
→ 不要过度解释。说完就停，把话语权交回去。越描越黑是这类问题最大的陷阱。

**没有相关行业经验**
"确实，我没在 <目标行业> 干过。我有的是 <稀缺组合>，
上一次我从零进入 <某领域> 用了 <N> 周做到 <结果> [证据·Bx]。"
→ 用"快速进入陌生领域"的既往证据，替代"我有相关经验"的谎话。

**降薪 / 降级转型**
"我很清楚这是一次重新开始，薪资上我接受 <区间>。
我看重的是 <长期理由>，这个判断我想了 <多久>，也为此做了 <具体准备>。"
→ 主动说出来，比等对方问出来的姿态好得多。
```

还要覆盖：频繁跳槽、职级倒退、学历门槛、年龄、原行业在收缩。

## Part D · 反问清单

准备 5 个问题，**分三类**，每类至少一个：

- **看清岗位真相**：这个岗位过去一年换过几个人？前任去哪了？——回答里的犹豫比内容更有信息量
- **看清成功标准**：入职 6 个月后，什么情况下你会觉得招对了人？
- **展示你的思考**：结合 03 模块读出的「隐藏痛点」提问——「JD 里提到要梳理现有流程，现在最卡的是哪一环？」这类问题的杀伤力最大，它证明你已经在想这份工作了

不要问薪资福利（留到 HR 环节），不要问官网上就有的信息。
